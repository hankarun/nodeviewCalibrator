# Node View Calibrator

A display calibration tool for multi-display setups with 3D visualization.
Ships as both an Electron desktop app (`desktop/`) and a web app (`web/`),
sharing logic in `src/`.

## Agent skills

### Issue tracker

Issues and specs live as local markdown files under `.scratch/<feature>/` in
this repo. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, each label string equal to its name. See
`docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at the repo root. See
`docs/agents/domain.md`.
